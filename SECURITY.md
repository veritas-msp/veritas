# Security Policy

## Supported versions

Security fixes are applied on the current `main` branch of this repository.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security problems.

Email: **security@veritas-msp.com**

Include:

- A short description of the issue
- Steps to reproduce or a proof of concept when possible
- Impact assessment (who can exploit it, what data is at risk)

We aim to acknowledge reports within a few business days.

## Safe disclosure

- Do not access data that is not yours.
- Do not disrupt production services.
- Give us reasonable time to fix and publish a patch before public disclosure.
